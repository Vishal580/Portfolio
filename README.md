# Vishal's Portfolio

A modern, responsive personal portfolio website showcasing my work as an SDET & Automation Engineer. Built with HTML, CSS, and JavaScript, featuring interactive elements and a clean design.

## 🚀 Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Interactive Navigation**: Hamburger menu for mobile with smooth animations
- **Parallax Effects**: Dynamic particle animations in the hero section
- **Project Showcase**: Highlighted projects with live demos and GitHub links
- **Contact Form**: Integrated contact form using FormSubmit for easy communication
- **Social Integration**: Direct links to GitHub, LinkedIn, Instagram, and email

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Custom styling with animations and responsive design
- **JavaScript**: Interactive functionality including parallax effects and slider
- **Font Awesome**: Icon library for social links and UI elements
- **FormSubmit**: Contact form handling service

## 🏃‍♂️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Vishal580/Portfolio.git
   cd portfolio-main
   ```

2. Open `index.html` in your web browser:
   - Double-click the file, or
   - Use a local server (recommended for better functionality):
     ```bash
     # Using Python
     python -m http.server 8000

     # Using Node.js
     npx serve .

     # Then open http://localhost:8000 in your browser
     ```
